# Electrical Vibers (VoltMaster Electricals)

A modern cross-platform Ionic Angular application for electricians and electrical service management.

## Tech Stack
- **Framework**: Angular & Ionic Framework (Standalone Components)
- **Mobile Runtime**: Capacitor (Android)
- **Styling**: SCSS & Angular Material
- **Backend / Database**: Firebase

## Development Server

Run `npm start` or `ng serve` for a dev server. Navigate to `http://localhost:4200/`.

## Build

Run `npm run build` to build the web project. The artifacts will be stored in the `www/` directory.

To sync with Android:
```bash
npx cap sync
npx cap open android
```
